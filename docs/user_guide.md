# User Guide

## Applications

The Applications tab lists all your recorded job applications in a table. Click **Add** to open the application form and record a new entry.

**Required fields:** Company, Role Title, Application Date, and Phase. All other fields are optional.

**Phase vs Status — what is the difference?**
*Phase* describes where you are in the hiring process — the steps you move through in sequence: Applied, Interview #1, Interview #2, Interview #3, and Final Stage. *Status* describes what has happened to the application — for example, whether it is under review, whether you have received an offer, or whether it has been rejected. You set the phase to reflect your current position in the process, and the status to reflect the outcome or current state. An application can have both: for example, Phase = Interview #2, Status = Reviewing.

**Priority** is a score from 1 to 5 that you assign to reflect how much you want the role. 1 is the lowest priority and 5 is the highest. Use it to sort or filter at a glance.

**Editing and deleting.** Select a row in the table and click **Edit** to update it, or **Delete** to remove it. The app will ask you to confirm before deleting.

**Filtering.** The toolbar above the table contains a search box and three filter dropdowns: Status, Phase, and Category. All active filters apply at the same time — for example, you can filter to Phase = Interview #1 and Category = Product Design simultaneously. Select "All" in any dropdown to clear that filter. The search box matches against company name and role title.

## Companies

The Companies tab manages the organisations you have applied to. Click **Add** to create a new company record.

**Contact details.** Each company can store a contact name, email address, and phone number (with a separate field for the country prefix, such as +44). These fields are optional and are there for your reference only.

**Industry.** The Industry field suggests existing values as you type, based on the industries you have already entered for other companies. You can type anything you like — it does not have to match a suggestion.

**Platform links.** You can attach multiple web links to a company — for example, a LinkedIn page, a Glassdoor profile, and a direct careers page. Click **+ Add link**, choose the platform from the dropdown, and paste the URL. Click the × button to remove a link. Links are saved when you click OK.

The app prevents duplicate company names and will not allow you to delete a company that still has applications linked to it.

## Analytics

The Analytics tab displays live charts and summary figures derived from your application data: total applications, active pipeline count, response rate, and average priority score. The funnel chart shows how applications progress through the key pipeline stages. Click **Refresh** to update all charts and figures after making changes in other tabs.

## Export

The Export tab lets you generate formatted reports from your application data. Select a report type from the dropdown — AfA table, application sheet, or analytics summary — configure any filters for that report, then click **Exportieren…** to choose an output directory and the file formats you want: PDF, Word, ODT, or LaTeX. When you choose the LaTeX format, the app saves a `.tex` file to your chosen folder; to compile it to a PDF you will need TexMaker installed separately (see the [installation guide](installation.md)). The other formats (PDF, Word, ODT) are generated directly without any additional software. The status label at the bottom of the tab confirms the output path on success, or shows the error in red if something goes wrong.

## Settings

The Settings tab lets you manage the reference values used throughout the application: statuses, categories, employment types, sources, work modes, and currencies. You can add new values, edit existing labels, and adjust the sort order in which they appear. If you no longer need a value, you can deactivate it — this hides it from the selection options in the application form but does not delete it from the database, so any existing records that used it are preserved intact.
