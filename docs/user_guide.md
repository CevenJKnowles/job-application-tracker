# User Guide

## Applications Tab

The Applications tab lists all your job applications in a sortable table. Use
the **+ Add** button to open the application form and record a new entry. Select
a row and click **Edit** to update it, or **Delete** to remove it after
confirmation. Use the search box, status filter, and category filter to narrow
down the list without reloading from the database.

## Companies Tab

The Companies tab manages the organisations you have applied to. Click **+ Add**
to create a new company entry. The application prevents duplicate company names
and will block deletion of any company that still has linked applications. Use
the search box or industry filter to find a specific entry quickly.

## Analytics Tab

The Analytics tab displays live charts and summary metrics derived from your
application data: total applications, active pipeline count, response rate, and
average priority score. Charts update whenever you click the **Refresh** button.
The funnel chart shows how applications progress through the key pipeline stages.

## Export Tab

Select a report type (AfA table, application sheet, or analytics summary) from
the dropdown, then configure the filters for that report. Click **Exportieren…**
to choose an output directory and the file formats you want (PDF, Word, ODT, or
LaTeX). The status label confirms the output path on success or shows the error
message in red on failure.

## Settings Tab

The Settings tab lets you manage the reference values used throughout the
application: statuses, categories, employment types, sources, work modes, and
currencies. Add new values, edit labels, adjust sort order, and deactivate
entries you no longer need. Deactivated values are hidden from dropdowns but
preserved in existing records.
